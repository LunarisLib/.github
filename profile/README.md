<div id="toc"><ul style="list-style: none;"><summary>
    <h2><b>About</b></h2>
</summary></ul></div>

*Lunaris is a project originally created by [Lohk](https://www.github.com/Lohkdesgds) and became a standard to his projects. Common C++ code and possibly public templates are made available here so anyone needing any of those tools can just download and use themself! There are several repositories useful to many applications, like simple **encryption using RSA**, **process calls**, **sockets** and so on. All of them should work with both Windows and Linux.*


<div id="toc"><ul style="list-style: none;"><summary>
    <h2><b>Format of the library</b></h2>
</summary></ul></div>

*The library follows these:*

- *Main classes are `CamelCase`, so this way you know what you are supposed to instantiate or use somewhere.*
- *Tools used by the main classes that may not make sense by themselves are usually `snake_case` -- like structs, small auxiliary classes, and so on.*
